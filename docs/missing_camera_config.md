## 一、算法能成立的成像前提（已知，不可乱动）

这几条不是相机参数，是**判据赖以成立的物理条件**——现场调光/换相机后但凡动到它们，判据就不再有效，
必须回炉重标 + 重跑零逃逸自检：

- **光路 = 同轴光垂直照。** 判据的三半径收敛（下条）就是在同轴垂直照明下量出来的。
- **光极性（这个坑踩过一次）**：判据认定「**有球 = 兜孔中心比台面暗** + 一个球面高光点」——凸球把同轴光
  反射回镜头形成一个小亮点，兜孔其余部分因压入而偏暗。**光极性一反，整批判定全错**（该 OK 判 NG、
  该 NG 判 OK 都可能）。所以改任何光路后，**必须**重跑 `tools/verify_l1_missing.py` 确认零逃逸才算数。
- **三种情况收敛到三个半径**（都以节圆半径 = 1）：
  | 情况 | 现象 | 精定位半径比 |
  |---|---|---|
  | 球压到位 | 暗盘 + 极亮球面高光点，球几乎填满孔口 | **≈ 0.157** |
  | 空兜（缺粒） | 透光亮孔（光穿过孔打到下方白底板），露出更小的孔底 | **≈ 0.118** |
  | 反面浮球 | 球没压进去（反面压不进去 → 即使球在表面也判 NG） | **≈ 0.13** |
  判据取「半径比 ≥ `0.144`（落在良品最低 0.152 与反面最高 0.133 的间隙里，靠 NG 侧）**且** 球面高光够强」。
- **反面是件级判、不是孔级隔离**：反面单槽也可能收敛到 ≈0.13 冒充有球，靠的是整圈**多个**空兜的统计裕度
  兜住整件（真产线反面每张有 5~7 个绿槽仍判 NG）。所以别指望「反面每颗球都被单独否掉」。

## 三、换相机 / 现场标定复检清单

上机或换相机后按顺序走，任一步不过不许往下：

1. **先离线**：`python src/flange_inspect/inspector_missing.py --mode local --dir <缺粒样本>`——不接硬件、
   不碰串口，确认判定日志出得来、判定合理。
2. **零逃逸自检**（硬闸）：`python tools/verify_l1_missing.py`——**改过任何成像/光路都要重跑**，
   逃逸恒为 0 才谈得上信它（当前 40 张 100% / 0 逃逸 / 0 过杀）。
3. **现场取图**：`--mode camera --ip 169.254.44.202`，确认建链、IO 硬触发一沿一帧、残帧标 `PARTIAL`、
   与传感器张数一一对齐（取图逻辑与第一站同源，出问题先照 `camera_config.md` 的取图清单查）。
4. **光极性核对**：肉眼/直方图确认「有球 = 中心暗 + 高光点」，别反（见「一」）。
5. **样本量**：现有 40 张偏小，攒更多缺粒/良品样本后复标 `BALL_R_RATIO_MIN` / `BALL_HIGHLIGHT_MIN`
   的间隙，再跑第 2 步。
